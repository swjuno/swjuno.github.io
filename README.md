# QuickFit Media ⚡

100% 브라우저 내 로컬 연산으로 동작하는 안전하고 빠른 무료 미디어 압축기 (서버 전송 0바이트)

## ✨ 주요 기능

- 🎬 **디스코드 영상 압축**: 영상 재생 시간을 실시간 분석해 25MB 이하로 자동 인코딩
- 📄 **정부24 · 청약 공공기관 서류**: 텍스트 가독성을 보존하며 1MB 이하로 경량화
- 💼 **취업 이력서 사진**: 사람인·잡코리아 규격에 맞춘 500KB 이하 리사이징
- 💬 **SNS · 카카오톡 최적화**: 웹 친화적인 고효율 WebP 포맷 변환
- 🔒 **100% 프라이버시 보호**: 외부 서버로 파일이 단 1바이트도 전송되지 않고 기기 내(RAM/GPU)에서만 처리

## 🛠️ 기술 스택

- HTML5, Vanilla JavaScript, Modern CSS
- WebCodecs API & Canvas Video Processing
- WebAssembly Image Compression
- Responsive Mobile-First Design
